# 指定した問題の Word 出力

## 変更範囲

問題選択画面に「Wordで出力」を追加。全問題の固定一覧番号、番号範囲、問題ID、チェックボックスで選べます。練習・チャレンジ01・チャレンジ02・分野・英文検索による絞り込みに対応。入力とチェックの順序を保ち、同じ問題は一度だけ出力します。不正な指定が混じる場合、途中までの指定を採用せずエラーにします。

クライアント側で DOCX を作成します。外部の生成AIや文書変換サービスに問題データは送りません。JIS B4 横向き 364×257 mm、2段組み、BIZ UDPGothic 11 pt が既定です。解答・日本語訳・全選択肢の説明は必ず次ページのセクションから始まります。出力内の番号は選択順の連番で、元のIDは解答側に残します。フォント未導入の端末では代替フォントになるため、ページ割りが変わる可能性があります。

原問題、選択肢、正答、和訳、解説、採点、学習履歴の保存処理は変更していません。解説の文章を短縮したり、新たな回答を生成したりもしません。

## 検証結果

- 既存22件と追加5件の単体テスト、合計27件成功。
- 型検査と Vite 本番ビルド成功。Word生成部分を遅延読み込みし、既存SW生成処理に新しいJSも含まれることを確認。
- 全180問の本文、訳、説明、選択肢別の理由、正答表示を生成DOCXと照合。元データが変更されていないことも検査。
- B4寸法、横向き、両セクションの2段組み、UDフォント指定、nextPage区切りをOOXMLで確認。
- 1問・10問・180問を実際にDOCX生成し、LibreOfficeで2・3・43ページにレンダリング。BIZ UDPGothicを使用し、全48ページの画像を確認。問題と解答のページが混在せず、ページ外への文字はみ出しなし。
- DOMシミュレーション11項目成功。入力エラー、選択保持、30問のチャレンジ切替、空検索、解除、チェック操作、連打での二重生成防止、DOCX Blobとファイル名の生成を確認。シミュレーションの非同期ZIP処理にはホストのsetImmediateを使用。
- ダークテーマの既存変数を再利用。新機能の入力欄だけ白地・白文字になる不具合をコード確認時に修正。

## まだ確認していないこと

実ブラウザでの画面表示、実際のダウンロード保存、iPhoneやAndroid、Microsoft Wordでの再レイアウトは未確認です。DOMシミュレーションと文書レンダリングを実ブラウザ確認と同一視しません。本番へは未反映です。

## 再実行

Node.js 24 と既存指定の pnpm を使用してください。

    pnpm install --frozen-lockfile
    pnpm test
    pnpm run check
    pnpm run build
    node --import tsx scripts/word-export-samples.ts

サンプル生成はプロジェクトの一つ上の outputs フォルダーに1・10・180問を保存します。問題データの今後の変更後にも、任意順・1問・全問で出力と表示を再確認してください。
