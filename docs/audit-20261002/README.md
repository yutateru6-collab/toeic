## 重要な修正例

- quiet / revise / installの別品詞用法を見落としていた誤答・説明を修正。
- insistの要求と事実主張の両義性、now thatの既知理由、nevertheless等の成立可能性を解消。
- betweenを「二者専用」と説明する誤りを除去。
- 予算＝実費とは限らない、入門動画も視聴必須になり得る、署名済み草案や要約も存在する、など文脈による別解の余地を縮小。
- eveningを「夜通し」とする訳などを修正。文法的に不可能な語と、通常文脈で最適でない語を区別。
